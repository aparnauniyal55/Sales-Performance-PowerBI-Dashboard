# 📊 Sales Performance Power BI Dashboard

## 📌 Project Overview

The Sales Performance Power BI Dashboard is an interactive business intelligence project developed using Microsoft Power BI.

The dashboard analyzes sales and revenue performance across different regions, products, categories, and time periods. It uses interactive filters, KPIs, charts, and a revenue heatmap to provide a clear overview of business performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📊 Dashboard Pages

### 1. KPI Indicators, Line Chart & Heatmap

This page provides an overview of the major sales performance indicators.

#### Key KPIs

- Total Revenue
- Target Achievement %
- Total Units Sold

#### Visualizations

- Monthly Total Revenue Line Chart
- Region-by-Month Revenue Heatmap
- Order Date Filter
- Region Filter
- Category Filter

### 2. Bar & Column Chart

This page focuses on regional and product-level performance.

#### Visualizations

- Total Revenue by Region
- Top-performing vs Underperforming Products
- Region Filter
- Order Date Filter
- Category Filter

## 🔍 Key Analysis Areas

The dashboard allows users to analyze:

- Revenue trends over time
- Revenue performance by region
- Product-level revenue performance
- Monthly regional performance
- Target achievement
- Units sold
- Top-performing products
- Underperforming products

## 🔄 Data Preparation

The data was prepared and transformed using Power Query.

The data preparation process included:

- Data cleaning
- Data transformation
- Data type modification
- Removing unnecessary data
- Creating calculated fields
- Preparing data for analysis

## 🧮 Data Modeling & DAX

The Power BI data model was used to connect the relevant tables and support interactive analysis.

DAX measures were created to calculate important metrics such as:

- Total Revenue
- Target Achievement %
- Total Units Sold

## 🎛️ Interactive Features

Users can interact with the dashboard using:

- Region slicer
- Category slicer
- Order Date slicer
- Interactive charts
- Cross-filtering between visuals
